# Images the upstream kagent 0.9.9 charts reference. Consumed by
# scripts/kagent-infra.sh, which docker-pulls each one on the host and then
# hands the set to scripts/kind-load-verified.sh — the same pull-to-host then
# prove-on-node pattern scripts/foundation-images.txt uses, and for the same
# reason: `kind load` can exit 0 having transferred nothing.
#
# ─── Why these are preloaded rather than left to the mirror ────────────────
#
# scripts/registry-cache.sh mirrors exactly five hosts: docker.io,
# registry.k8s.io, ghcr.io, quay.io and mirror.gcr.io. cr.kagent.dev is not
# among them and there is no hosts.toml for it on the node, so the three
# cr.kagent.dev images below would be pulled straight from the internet by
# every kubelet on every cold cluster, with no cache and no verification that
# they arrived. Preloading them makes the install deterministic; the ghcr.io
# and docker.io entries are preloaded alongside them so one list covers the
# whole control plane rather than two mechanisms covering half each.
#
# Lines are `REFERENCE` or `REFERENCE  # comment`. Blank lines and comments are
# skipped. The OBSERVABILITY marker below splits the file: everything above it
# is always loaded, everything below it only when ENABLE_OBSERVABILITY=true.

cr.kagent.dev/kagent-dev/kagent/ui:0.9.9
ghcr.io/kagent-dev/kagent/tools:0.2.1
docker.io/library/postgres:18.3-alpine
