## Governance Operating Model

Every agent action follows an evidence-based verification loop:

1. **Attestation**: The agent presents a cryptographic SPIFFE verifiable identity document.
2. **Policy Verification**: The engine evaluates permissions against formal security bounds.
3. **Dynamic Credentialing**: OpenBao issues a short-lived lease for the specific operation.
4. **Execution and Monitoring**: The host sensor observes system calls without reading payload data.
5. **Immutable Audit**: The platform records a SHA-256 hash digest in the append-only ledger.
