The **Signal Loom Enforcement & Response (SLER)** architecture quantifies containment guarantees through two distinct, benchmarked metrics for every enforcement plane:

1. **Guaranteed Denial Latency (p99):** The maximum observed elapsed time for the control plane to issue and enforce the containment directive.
2. **Worst-Case Residual Latency:** The maximum window of opportunity during which existing, previously-minted tokens, cached secrets, or in-flight connections could theoretically remain valid under network partitioning or client-side caching.

## 2. Multi-Plane Combined Load Fleet Scale Benchmarks

To ensure individual plane guarantees hold during concurrent system-wide incidents, Fleet Manager exercises all five planes simultaneously using goroutine fan-out under a shared context budget:

| Fleet Scale Tier | Agent Count | Total Plane Operations | p50 Latency | p90 Latency | p99 Latency | Documented Regression Ceiling | Status |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Single Agent (`single_agent`)** | **`1`** | **`5`** | `1.0 ms` | `2.1 ms` | **`4.8 ms`** | `25 ms` | **PASS** |
| **Demo Fleet (`demo_fleet`)** | **`5`** | **`25`** | `3.2 ms` | `6.4 ms` | **`11.5 ms`** | `40 ms` | **PASS** |
| **Scale Fleet (`scale_fleet`)** | **`64`** | **`320`** | `14.8 ms` | `24.2 ms` | **`42.0 ms`** | `100 ms` | **PASS** |
| **Max Mission Fleet (`max_fleet`)** | **`256`** | **`1,280`** | `48.5 ms` | `82.0 ms` | **`135.0 ms`** | `300 ms` | **PASS** |

### Fleet Baseline Alignment
- **Single Agent (N=1):** Sub-5ms response for targeted surgical containment.
- **Demo Fleet (N=5):** Exactly matches the 5-agent demonstration topology in `d2-signalloom/apps/fe-signalloom/base/fleet.yaml`.
- **Scale Fleet (N=64):** Evaluates multi-tenant cluster scale an order of magnitude above baseline.
- **Max Mission Fleet (N=256):** Validates the system ceiling for star-topology cascade benchmarks.

## 4. Automated CI Regression & Benchmarking

The denial matrix is validated continuously against the codebase to prevent regression or latency drift:

```bash
# Execute unit contract tests and JSON export validation
cd d2-signalloom/apps/fleet-manager && CGO_ENABLED=0 go test -v -run TestDenialMatrix ./...

# Execute multi-plane scale microbenchmarks
cd d2-signalloom/apps/fleet-manager && CGO_ENABLED=0 go test -bench=BenchmarkDenialMatrix -run=^$ ./...
```
