# Retest Plan: SLAWS & SLAAT Cross-Plane Permutation Suites (2026-Q4)

This document specifies the unified adversarial and telemetry retest plan. It executes one-shot permutations across SLAWS and SLAAT.

## 1. Executive Summary & Context

Signal Loom combines runtime telemetry ingestion with kernel-enforced multi-tenant isolation. Two independent validation missions established the current platform baseline:

- **SLAWS (AWS Telemetry Ingest & Multilayer Policy Beta):** Ingestion pipeline for CloudTrail, VPC Flow, and IAM events (`collectors/awslogs`). High-performance analytical storage in FrostDB (`SIGNAL_STORE=frostdb`). Offline synthetic replay (`signal-ingest replay --bundle --from --to`). Declarative multi-layer CEL observation policies (`pkg/obscel`).
- **SLAAT (Whole-System Autonomous Adversarial Testing):** Autonomous exploit testing across five defense surfaces. Surface 1: Ingress gateway routing and network microsegmentation. Surface 2: Backend API authentication, Dex OIDC tokens, and multi-tenant IDOR. Surface 3: SPIFFE workload identity and OpenBao JWT credential delegation. Surface 4: OpenBao secrets path isolation and ACL enforcement. Surface 5: Sentinel eBPF monitoring, cgroup-freezing, and Landlock LSM containment.

Prior testing evaluated these systems in isolation. This retest plan validates cross-plane invariants under concurrent adversarial load and high-volume telemetry ingestion.

## 2. Cross-Plane Invariant Boundaries

The retest matrix asserts four operational invariants across both platforms:

1. **Adversarial Fail-Closed Invariant:** Active exploit probing against any SLAAT attack surface must be blocked immediately. Ingress drops spoofed headers. Unauthorized API requests yield HTTP 401 or 403. Invalid SPIFFE requests fail attestation. Probed OpenBao paths return 403. Landlock containment traps prohibited syscalls.
2. **Telemetry Ingest Resilience Invariant:** High-volume adversarial attacks must not degrade telemetry collection. Ingest buffers must drop zero observations. Disk ring buffers must not overflow. FrostDB must flush clean Parquet files with zero schema corruption.
3. **Observational Detection & Correlation Invariant:** Security events generated by adversarial activity must appear in the telemetry stream. The multi-layer policy engine must match events against CEL bundles and emit security findings.
4. **Deterministic Replay Invariant:** Replaying synthetic event streams through offline harnesses must yield identical CEL policy evaluations to live execution.

## 3. The Five Permutation Suites

The one-shot test battery defines five permutation suites:

### Suite 1: Ingress Spoofing & Network Bypass under High-Throughput VPC Flow Ingest

- **Target Attack Surface (SLAAT Surface 1):** Probing Envoy Gateway routes, forging client IP headers, and attempting cross-namespace traversal to internal datastores (PostgreSQL 5432, MinIO 9000).
- **Concurrent Telemetry Ingestion (SLAWS):** Active collection of synthetic VPC flow logs and gateway connection logs into `signal-ingest`.
- **Expected Outcome:** Envoy Gateway strips untrusted client headers per `ClientTrafficPolicy`. NetworkPolicy drops unauthorized pod-to-pod traffic. Ingest pipeline captures flow records and writes them to FrostDB without packet loss.

### Suite 2: API IDOR & Token Replay under CloudTrail Audit Ingestion & CEL Evaluation

- **Target Attack Surface (SLAAT Surface 2):** Fuzzing FastAPI endpoints, replaying expired Dex OIDC JWTs, and submitting cross-tenant resource IDs in workspace discovery and posture routes.
- **Concurrent Telemetry Ingestion (SLAWS):** Streaming CloudTrail management events and API audit trails through `pkg/obscel` CEL evaluator with Stage 1 and Stage 2 windowed rules.
- **Expected Outcome:** Backend API rejects forged tokens with HTTP 401 and cross-tenant queries with HTTP 403. Policy engine detects anomaly signatures and emits `policy_finding` records in real time.

### Suite 3: SPIFFE Workload SVID Forgery under Workload Observation Ingestion

- **Target Attack Surface (SLAAT Surface 3):** Attempting SPIRE Workload API attestation from unregistered pods and requesting cross-tenant OpenBao JWT role exchanges.
- **Concurrent Telemetry Ingestion (SLAWS):** Ingesting workload lifecycle observations and attestation telemetry into the FrostDB analytical store.
- **Expected Outcome:** SPIRE agent rejects attestation for unregistered workloads. OpenBao refuses token delegation. Observation pipeline captures failed attestation signals into Parquet partitions.

### Suite 4: OpenBao Secrets Traversal under Synthetic Policy Replay

- **Target Attack Surface (SLAAT Surface 4):** Fuzzing OpenBao KV paths (`secret/data/...`) across tenant boundaries and evaluating token TTL expirations.
- **Concurrent Telemetry Ingestion (SLAWS):** Executing `signal-ingest replay` with security policy bundles (`policy/bundles/kusari/iam-change.yaml`) against live audit recordings.
- **Expected Outcome:** OpenBao denies unauthorized path reads. Token leases expire within the 300-second window. Synthetic replay produces matching finding counts to the live baseline.

### Suite 5: Sentinel Burst Evasion & Landlock Escape under FrostDB Parquet Compaction

- **Target Attack Surface (SLAAT Surface 5):** Triggering rapid process spawn bursts and attempting writes to sensitive filesystem paths (`/etc`, `/root`, `~/.kube`) from confined sandboxes.
- **Concurrent Telemetry Ingestion (SLAWS):** Heavy disk ring-buffer writes and Parquet column compaction in FrostDB.
- **Expected Outcome:** Sentinel eBPF detects process bursts and triggers cgroup freezing. Landlock LSM restricts unauthorized path writes (`EACCES`). FrostDB storage operations proceed without data loss or race conditions.

## 4. Execution Harness Architecture

A unified test harness drives the five suites:

- **Orchestration Script:** `scripts/slaws-slaat-permutation-matrix.sh` wraps all five suites, providing `--dry-run`, `--suite <name>`, and structured JSON output.
- **BATS Test Suite:** `test/slaws-slaat-cross-plane-probes.bats` executes the permutation matrix and asserts exit codes and evidence artifacts.
- **Evidence Ledger:** All probe results, status codes, and execution timings are recorded in `ci-evidence/slaws-slaat-permutation-baseline.json`.
