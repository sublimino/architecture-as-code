---
title: Glossary
description: Use one approved term for each platform concept.
---

| Term | Meaning |
| :--- | :--- |
| **agent** | A governed software actor recorded in the Signal Loom inventory. |
| **slice** | One D2 delivery boundary that owns namespaces, images, tests, and lifecycle. |
| **foundation** | The shared Kind, Zot, signing, Flux, ingress, and monitoring substrate. |
| **lane** | One GCP environment such as `demo-1` or `ci-1`. |
| **estate** | The software stack deployed to a lane VM. |
| **stun** | Apply containment controls to an agent workload. |
| **unstun** | Remove applied containment controls from an agent workload. |
| **superadmin** | A demonstration identity allowed to run privileged instructor actions. |
| **operator** | The current API label for an authenticated non-superadmin principal. |
| **evidence** | An observed record used to support a governance decision. |

Do not use **lane** as a synonym for **estate**. Do not describe the current
`viewer` demonstration account as technically view-only.
