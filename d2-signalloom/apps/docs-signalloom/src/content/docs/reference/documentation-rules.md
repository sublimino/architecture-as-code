---
title: Documentation rules
description: Write direct, consistent software documentation using the repository STE-Code adaptation.
---

These rules adapt STE-Code for this repository. They do not claim complete
STE-Code Level 5 compliance.

1. Use the project glossary before you add a technical term.
2. Use one term for one concept.
3. Use technical nouns only as nouns.
4. Use technical verbs only as verbs.
5. Preserve exact commands, identifiers, API fields, and product names.
6. Use British English in prose.
7. Start an instruction with a direct action.
8. Put a condition before its required action.
9. Give one primary action in each numbered step.
10. State the expected result of each check.
11. Put a warning before the risky action.
12. Separate verified behaviour from roadmap behaviour.

Prefer “Run the script to start the service.” Do not write “Leverage the script
to bootstrap the service.”
