🎯 The Problem We Solved

As Signal Loom onboards enterprise design partners (e.g. Kusari), customer requirements bifurcate:

  • Navigation Clutter: Enterprise pilots need focused agent telemetry and containment. Experimental demo routes (SuperCred, RBAC Analysis, Collusion) must not distract operators.
  • Static Identity Bottleneck: User administration previously relied on static configuration maps or direct database inserts rather than a web console.
  • SaaS Sprawl Trap: Commercial flagging tools (LaunchDarkly, Unleash daemons) add costly egress, latency, and operational attack surfaces.

✨ The Solution Architecture

A CNCF OpenFeature-compliant architecture running directly on our PostgreSQL + FastAPI foundation:

  • OpenFeature React SDK: Declarative <FeatureGate> wrappers prevent layout shifts (CLS) and gate routes seamlessly.
  • Dynamic OIDC Authority: Normalized Dex JWT claims resolve live against platform_users, rejecting suspended accounts immediately with 403.
  • Superadmin User Console: Complete user lifecycle UI in Settings with role assignment, invitation modals, and multi-tenant isolation.

🔒 Strict Tenant Isolation

All database queries strictly filter by tenant_id. Superadmins can query across tenants, while Tenant Admins are restricted solely to their partition.

🚫 Suspended Account Defense

When an operator status is toggled to suspended in platform_users, authenticated_principal immediately aborts token evaluation with HTTP 403 (account_suspended). There is zero delay or caching lag.

⚡ Client Fallback Containment

If a non-admin directly loads /admin/users in their browser, AdminRoute blocks rendering and redirects. If a non-admin bypasses the client and hits /api/v1/admin/users, FastAPI returns HTTP 403 Forbidden.
