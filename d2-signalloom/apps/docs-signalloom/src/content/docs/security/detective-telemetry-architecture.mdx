Signal Loom's **Coding Agent & Harness Detective Telemetry** (`SLCD v0.1.0`) provides real-time, passive observability into autonomous coding agent execution across developer workstations and build nodes. Operating strictly as a non-intrusive observer, the detective pipeline identifies active agent harnesses, correlates autonomous task loops, tracks token throughput, and maps outbound model egress—all while strictly enforcing the [Zero-Customer-Payload Privacy Invariant](/docs/security/zero-customer-payload/).

## 1. Strictly Detective Posture

Unlike active governance agents or debug proxies, Signal Loom's detective telemetry operates under three foundational constraints:

1. **Zero Model Context Protocol (MCP) Handshakes**: The sensor never connects as an MCP client or server, never injects RPC commands, never queries agent tools, and never registers governance hooks into agent configurations.
2. **Passive Operating System Inspection**: The sensor extracts telemetry using standard unprivileged Linux kernel interfaces (`procfs`, `cgroupfs`, `sock_diag`). It never attaches debuggers (`ptrace`), never injects shared libraries (`LD_PRELOAD`), and never pauses process execution.
3. **Zero Payload Ingestion**: The entire pipeline operates exclusively on allowlisted numeric counters, enumerated categorical identifiers, timestamps, and cryptographic digests. Source code diffs, prompts, and credentials never cross the process boundary.

### 2.1 Procfs Bounded Extraction (`proc.py`, `scanner.py`)
- **Allowlisted Stat Fields**: The sensor reads `/proc/<pid>/stat`, `/proc/<pid>/status`, and `/proc/<pid>/statm` to collect process IDs (`pid`, `ppid`), binary command name (`comm`), resident memory (`rss_bytes`), and CPU user/system time (`cpu_ticks`).
- **Pre-Collection Chokepoint**: `proc.py` defines `PROHIBITED_PROC_ENTRIES` (`cmdline`, `mem`, `environ`, `fd`, `fdinfo`, `net`, `cwd`, `root`, `syscall`, `stack`). Any attempt to open a prohibited procfs path immediately raises `SecurityException` *before* `open()` is called.
- **Bounded Basename Resolution**: Binary identification resolves exclusively to the executable basename (`os.path.basename(os.readlink('/proc/<pid>/exe'))`) to prevent argument leakage from command line strings.

### 2.2 Harness Classification Engine (`classifier.py`)
The classifier evaluates multi-signal heuristics across 7 supported coding agent harnesses:

| Harness Type | Comm / Executable Basename | Known Cgroup / Runtime Signature | Primary Inference Protocol |
|---|---|---|---|
| `claude` | `claude`, `node` | `.claude/`, npm/npx wrappers | Anthropic HTTPS API |
| `antigravity` | `antigravity`, `agy` | `.gemini/antigravity-cli/` | Google Cloud / Gemini API |
| `codex` | `codex`, `codex-exec` | `.codex/` | OpenAI HTTPS API |
| `cpai` | `cpai`, `kpai`, `omp` | `.cline/`, `.cpai/` | Multi-provider / OpenBao |
| `opencode` | `opencode` | `.opencode/` | OpenCode Runtime / Ollama |
| `hermes` | `hermes` | `.hermes/` | Hermes Agent Loop |
| `aider` | `aider`, `python3` | `.aider/` | Multi-model / LiteLLM |

### 2.3 Kanban Task Correlation (`kanban.py`)
- **Non-Blocking Shared Descriptors**: The sensor inspects local task files (`board.json`, `.cycle.json`, `sessions.json`, `kanban.sqlite`) using read-only descriptors (`O_RDONLY`, `?mode=ro`). It never acquires exclusive filesystem locks (`flock`) and never delays kanban controller loops.
- **Monotonic Clock-Skew Defense**: Anchors cycle duration (`elapsed_s`) using monotonic progression timestamps (`monotonic_anchor_ns`), ensuring durations remain positive even across host NTP adjustments or VM sleep/resume events.
- **Strict Allowlist**: Extracts only `task_id`, `shortcode`, `role`, and `elapsed_s`. Task prompt descriptions and activity strings are discarded.

### 2.4 Transcript Metadata Extraction (`transcript.py`)
- **Positive Field Rule Tables**: Maps transcript structures (`FORMAT_RULES`) over a strictly finite allowlist of key paths (11 paths for Claude, 7 for Antigravity, 7 for Codex, 3 for Hermes).
- **Leaf Type Funnels**: Coerces numeric tokens (`coerce_count`) with integer overflow clamping (`MAX_COUNT = 2**53 - 1`), maps model names to enum `ModelFamily`, and canonicalizes RFC3339 timestamps.
- **Tool Name Normalization**: Normalizes standard tool names (`view_file`, `write_to_file`, `run_command`, `grep_search`, `list_dir`, etc.) into a 13-key histogram; unmapped tools fold into `other_count`.

### 2.5 Netlink Socket Inode Attribution (`network.py`)
- **Kernel Socket Attribution**: Utilizes `NETLINK_SOCK_DIAG` to extract active TCP sockets with `INET_DIAG_CGROUP_ID`, matching the socket to the process cgroup via `name_to_handle_at(2)`. This avoids reading `/proc/<pid>/fd` directly.
- **Tiered CIDR Matching**: Matches remote IPs against [Inference Provider Ranges](/docs/reference/inference-provider-ranges/) across `dedicated`, `shared`, and `loopback` tiers.
- **Control-Plane Exclusion**: Connections to secrets managers (`openbao` on port 8200) are classified as `control-plane` and strictly excluded from inference telemetry.

## 3. Signal Ingestion Pipeline (`signal-ingest`)

The Go ingestion service (`signal-ingest`) terminates host sensor uploads and persists validated records:

1. **Ingestion Endpoint**: `POST /api/v1/telemetry/coding-agent` (and `fe-signalloom-api` BFF proxy `/api/v1/telemetry/coding-agents`).
2. **Schema & Wire Contract Validation**: Validates the payload against the frozen `codingagent.v1` schema (`d2-signalloom/apps/signal-ingest/codingagent/types.go`). Excess or unrecognized properties are rejected.
3. **Cryptographic Deduplication & Storage**: Computes an idempotent event digest and stores telemetry in the active time-series memory buffer and storage engine.
4. **Tenant Isolation**: Associates incoming host telemetry with the authenticated organization tenant ID.
