🛡️ Six-Layer Defense-in-Depth Confinement Architecture

Every autonomous agent and external invocation traverses six independent, interlocking security controls:

📜 LAYER 6

Cryptographic Merkle Audit & OpenFAIR Risk

Every tool execution and admission is hashed into an append-only Merkle ledger (AIGF). Quantitative OpenFAIR risk computes Annualized Loss Expectancy (ALE).

FINOS AIGF · OpenFAIR
🎛️ LAYER 5

Application Feature Gates & Dynamic Auth

CNCF OpenFeature React SDK gates UI surfaces. FastAPI authenticated_principal verifies Dex OIDC JWTs against database user states, immediately dropping suspended accounts.

OpenFeature · Dex OIDC
🌐 LAYER 4

L7 Gateway CEL Authorization & Inline DLP

Envoy / AgentGateway evaluates CEL tool allowlists and inline Lua filters. Blocks mutating verbs (send, delete, truncate) on read-only external interfaces in ~0.25ms.

Envoy Gateway · CEL
🔐 LAYER 3

Workload Cryptographic Identity & Ephemeral Leases

SPIFFE X.509 SVIDs minted via SPIRE CSI driver. OpenBao issues short-lived 300s credential leases. Static tokens are banned from process environments.

SPIFFE / SPIRE · OpenBao
🔒 LAYER 2

Landlock LSM & System Call Sandboxing

nono enforces kernel Landlock rules denying ~/.ssh, ~/.gnupg, and raw token files. Restricts filesystem read/write and network namespaces per process.

Landlock ABI-5+ · nono
🧱 LAYER 1

Host Isolation, Namespaces & cgroups v2

Unprivileged user namespaces (UID 1000), read-only root filesystems, PR_SET_NO_NEW_PRIVS, and cgroups v2 memory/CPU throttle limits.

cgroups v2 · AppArmor
