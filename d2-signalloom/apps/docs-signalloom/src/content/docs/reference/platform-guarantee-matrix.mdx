## 1. The Three Architectural Layers

### Layer 1: OBSERVE (Detective Telemetry)
The foundational sensory plane. Observes process lifecycles, network socket lifecycles, file system mutations,
and identity invocations. Telemetry streams into FrostDB with zero customer payload capture (metadata only).

### Layer 2: GOVERN (Policy & Active Containment)
The enforcement plane. Evaluates agent activity against defined behavioral boundaries and executes active
containment when anomalies occur (SLER 3-plane kill-path: execution freeze with healthz replay, dynamic
credential revocation, and eBPF TC packet severance).

### Layer 3: ATTEST (Supply Chain & Cryptographic Verification)
The trust verification plane. Establishes cryptographic proof of workload identity (SPIFFE SVIDs),
container image provenance (SLSA Level 3), artifact signatures (Cloud KMS Cosign), and operational audit
immutability.

## 3. Graceful Degradation & Fallback Strategy

When deploying across environments with varying privilege levels, Signal Loom dynamically adapts:

1. **Kernel Privilege Unavailable**:
   If `CAP_BPF` or `CAP_SYS_ADMIN` is denied by node security policy, the agent daemon gracefully
   falls back from eBPF TC filtering to Kubernetes `NetworkPolicy` egress isolation, while routing
   LLM model traffic through the `cpai` proxy circuit breaker.
2. **Cgroup V2 Unavailable**:
   In container environments where host `/sys/fs/cgroup` cannot be mounted, execution freeze degrades
   to container SIGSTOP or immediate pod deletion, bypassing the 300s forensic investigation lease.
3. **EU Works Council Jurisdictions**:
   In Germany, France, and the Netherlands, the workstation sensor is automatically disabled by the
   **EU Jurisdiction Geo-Guard** (`config.compliance.jurisdiction_guard = true`), limiting observation
   strictly to autonomous non-human backend workloads.
