## STATEFUL store requirements
Module-level, per-tenant, lock-guarded:
```
_STORE_LOCK = threading.Lock()
_AGENTS: dict[str, dict[str, dict]] = {}          # tenant_id -> agent_id -> AgentResponse-dict
_VIOLATIONS: dict[str, dict[str, dict]] = {}       # tenant_id -> violation_id -> ViolationResponse-dict
_NHI_ACCOUNTS: dict[str, dict[str, dict]] = {}     # tenant_id -> account_id -> NHIAccount-dict
_TENANT_FRAMEWORKS: dict[str, list[str]] = {}      # tenant_id -> selected frameworks
```
- Lazy-seed per tenant on first access, all under the lock so concurrent first hits don't double-seed: 1-3 realistic agents, 1-3 violations, 1-3 NHI accounts, default frameworks, default cookie prefs.
- GET /agents returns the seeded + created agents for that tenant; total = len.
- POST /agents: generate an id (e.g. f"{tenant_id}:agent-{n}"), lifecycle_state e.g. "registered", created_at = now ISO, append to store, return the AgentResponse. Then GET /agents and GET /agents/{id} must include it.
- GET /agents/{id}: if unknown id, SYNTHESIZE a deterministic AgentResponse for that tenant (id echoed back) rather than 404, so a standalone GET works without a prior POST.
- POST /agents/{id}/transition: update that agent's lifecycle_state to body.to_state, last_transition_at=now, last_transition_by=actor; return TransitionResponse (from_state = prior state). If agent unknown, synthesize prior state "registered".
- GET violations: seeded list for tenant.
- POST acknowledge: flip that violation's status to "acknowledged" in store (seed a matching violation id if unknown); return {"status": "acknowledged"}.
- reassess: return ReassessmentResponse with status "reassessment_requested".
- NHI discovered: seeded accounts; enroll → status "enrollment_requested"; dismiss → status "dismissed"; return {account_id, status}.
- tenant/settings: cookie_preferences default {strictly_necessary: true, analytics: false}; selected_frameworks from _TENANT_FRAMEWORKS (seed a default like ["eu-ai-act"]).
- PATCH /tenant/settings/frameworks: set _TENANT_FRAMEWORKS[tenant]=body.selected_frameworks, return TenantSettingsResponse reflecting them.
- consent/status + accept, cookie-preferences get/patch: canned/stateful as cheap.
